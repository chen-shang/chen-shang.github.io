DATABASE

安装 DBHub

1

创建配置文件

Terminal
mkdir -p ~/.config/dbhub
nano ~/.config/dbhub/dbhub.toml

把下面内容粘进去，只修改大写占位符：

~/.config/dbhub/dbhub.toml
# MySQL 开发环境
[[sources]]
id = "dev"
dsn = "mysql://READONLY_USER:ENCODED_PASSWORD@DB_HOST:3306/DATABASE?sslmode=require"

[[tools]]
name = "execute_sql"
source = "dev"
readonly = true
max_rows = 500

[[tools]]
name = "search_objects"
source = "dev"
READONLY_USER数据库只读用户名
ENCODED_PASSWORDURL 编码后的密码
DB_HOST数据库地址
DATABASE数据库名称
必须做

数据库账号本身也要设置成只读。readonly = true 是第二层保护，不能代替数据库权限。

保存后执行
chmod 600 ~/.config/dbhub/dbhub.toml
2

注册到 Codex

Terminal
codex mcp add dbhub -- \
  npx -y @bytebase/dbhub@latest \
  --transport stdio \
  --config "$HOME/.config/dbhub/dbhub.toml"
02

EMAIL

安装 email-mcp（QQ 邮箱）

1

先拿到 QQ 邮箱授权码

  1. 登录 QQ 邮箱网页版。
  2. 打开 设置 → 账号。
  3. 找到 POP3 / IMAP / SMTP 服务并开启。
  4. 生成客户端授权码。
注意

后面 Password 填授权码，不填 QQ 登录密码。不要把授权码发给任何人，也不要放进 Git。

2

运行配置向导

Terminal
npx -y @codefuturist/email-mcp@latest setup

向导会提示 QQ 无法自动识别，这是正常的。每一项这样填：

字段填写内容
Account nameqq
Email address完整 QQ 邮箱地址
Full name你的昵称，可自定义
IMAP host / port / TLSimap.qq.com / 993 / Yes
SMTP host / port / securitysmtp.qq.com / 465 / TLS
Connection poolingYes / 3 / 100
Username完整 QQ 邮箱地址
Password / App PasswordQQ 客户端授权码，不是登录密码
3

测试邮箱，再注册到 Codex

Terminal
# 先测试 IMAP 与 SMTP
npx -y @codefuturist/email-mcp@latest test qq

# 测试通过后，注册到 Codex
codex mcp add email -- \
  npx -y @codefuturist/email-mcp@latest stdio
继续标准测试结果里 IMAP 和 SMTP 都成功，再执行注册命令。

PROMPTS

安装后的使用示例

DBDBHub

先看数据库结构

请使用 DBHub 搜索当前数据库的所有表，只返回表名和说明，不要执行修改操作。

DBDBHub

执行只读查询

请先查看 orders 表的字段，再生成并执行一条只读 SQL，返回最近 20 条记录。

@email-mcp

TROUBLESHOOTING

只看这四个常见问题

Unsupported engine

Node 太旧，升级到 Node.js 24 或更高。

Provider not auto-detected

QQ 邮箱的正常提示，继续手动填写服务器参数。

Authentication failed

确认填的是 QQ 客户端授权码，并且已经开启 IMAP / SMTP。

Codex 看不到工具

先执行 codex mcp list，再完全重启 Codex。

数据库密码包含特殊字符怎么办？

DSN 中的密码如果包含 @ / : ? # % 等字符，需要先做 URL 编码。不要把真实密码放进在线编码网站，也不要发到聊天里。

DONE

到这里就装完了

先用只读 Prompt 验证，再逐步开放写入、移动邮件或发送邮件等高影响操作。
