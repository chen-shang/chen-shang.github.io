01

AI 基础知识科普

智能的本质：东西方的两条路

古人把"智能"拆成两个字——智（知 + 日，认知的积累与升华）与 能（甲骨文像熊，天赋力量经磨砺成才能）。东方讲知行合一（知人者智、自知者明），西方讲推理 + 目标（亚里士多德、笛卡尔、图灵测试）。真正的智能不只是知道，而是做到。

AI 的三级台阶：从专用到超越

ANI

弱人工智能

专精特定任务（Siri、图像识别、AlphaGo、GPT）。今天绝大多数 AI 仍在此层，无法跨领域迁移。

AGI

通用人工智能

达到人类级别的全面认知，能跨领域推理、自主学习、制定计划。尚未有公认实现，是核心目标。

ASI

超人工智能

几乎所有领域超越人类（Bostrom《Superintelligence》）。时间线未知，争议极大。

实现智能的三种角度 → 三大流派

工程上不等问题完全想明白才开始——飞机也是先飞起来的。三种思路演进成交替领先又彼此融合的三大流派：

Connectionism

连接主义

从"大脑"出发，模仿神经元连接与学习。黄金时代是 2010 年代至今的深度学习与大语言模型。

Symbolic AI

符号主义

从"行为"出发，把知识编码成符号与规则做逻辑推理。代表：DENDRAL、MYCIN、知识图谱。

Behaviorism

行为主义

从"交互"出发，让智能在感知-行动闭环中涌现。代表：AlphaGo、具身智能、机器人学。

AI 前世今生：一条时间轴

1936

图灵机 — 可计算性的基石

24 岁的图灵严格定义"什么是可计算"，为一切计算装置划定理论边界；但"计算"不等于"智能"。

1943

MP 模型 — 数学神经元的诞生

McCulloch & Pitts 用数学公式模拟生物神经元，证明网络可执行基本逻辑运算（权重仍需手动设置）。

1956

达特茅斯会议 — AI 正式启航 ★

McCarthy、Minsky、Shannon、Rochester 召开研讨会，正式提出"人工智能（AI）"这一术语——AI 作为独立领域诞生。

1980s

寒冬与复兴

符号主义因常识无法写成规则而碰壁，AI 寒冬降临；随后连接主义与行为主义先后重新夺回中心。

2010s+

深度学习与 LLM 时代

算力、数据与神经网络共振，深度学习爆发；大语言模型把 AI 推向大众与真实工作流。

02

Agent 使用实战

LLM 像军师，Agent 像士兵，你是指挥官

LLM 负责分析、推理、生成内容，但默认进不了仓库、执行不了命令；给它加上工具 / 权限 / 循环，它就变成 Agent——观察、行动、验证、继续，直到完成任务或触发人工确认。Agent 再强，方向错了也要你纠偏。

Agent 不是一种，而是四类

CHATTING

Chatting Agent

豆包、Kimi 等对话助手，适合问答、检索、知识解释，当更聪明的搜索引擎。

CODING

Coding Agent

读仓库、改代码、跑测试，把研发任务推进到可验证、可交付的结果。

WORKING

Working Agent

处理文档、邮件、表格、会议、审批与跨系统协作，完成真实工作流。

OTHER

Other Agent

研究、数据分析、客服、电脑操作、多 Agent 协作等专业场景。

一套顺手的工具箱（不追求"一个最强"）

程序员用 Coding Agent 组合：Codex CLI（仓库开发主力）+ ChatGPT（图形化协作）+ Claude Code / OpenCode（复杂任务与多模型补位）。业务员优先选与办公生态一致的产品：WorkBuddy + 微信/企业微信、TRAE Work + 豆包、QoderWork + 悟空。真正值得沉淀的是：清楚每个工具的强项与边界，知道什么时候切、为什么切。

MCP / A2A / Skill：不在同一层

TOOL

一个原子动作

读文件、执行 SQL、建 Issue——关心"这一步能做什么"。

MCP

连接工具与上下文

用统一方式发现并调用外部能力，减少每接一个系统都重写私有集成。

A2A

Agent 之间协作

面向 Agent 间通信：发现能力、委派任务、交换消息、交付结果。

SKILL

可复用的做事方法

用入口文件描述触发条件、步骤与约束，沉淀"这类事该怎么做"。

一句话：团队规则约束 → Skill 组织 → Agent 通过 MCP 调用 Tools/Data → 必要时经 A2A 连其他 Agent。不装 Skills 和 MCP 的 Agent，难以完成长链路任务。

使用 AI 的八条安全红线

01数据红线
不直传秘密、隐私与内部资料

密码、API Key、证件、客户数据、源代码——先用示例数据，能脱敏就脱敏。

02权限红线
不授予全盘、长期权限

用独立账号、只读、限定目录、短期凭证；任务结束立即收回。

03执行红线
不无确认执行不可逆操作

删除、转账、发布、批量改权限——先预览、再审批、后执行、可回滚。

04判断红线
不把 AI 回答当确定事实

医学、法律、财务、人事决定尤其不能只依赖 AI，需有资质者复核。

05行为红线
不利用 AI 欺骗、攻击、伤害

不制作钓鱼、诈骗、恶意程序或绕过安全控制。

06诚信红线
不伪造身份、证据、来源

该标注 AI 辅助就标注；引用必须能回到真实可验证来源。

07权利红线
不忽视版权与保密义务

第三方作品、客户文件、内部文档不会因"交给 AI"就自动获授权。

08指令红线
不让网页/邮件偷偷接管 AI

外部内容可能有恶意指令（提示词注入），一律视为不可信数据。

GATE 01 · 输入前
这份数据真的需要给吗？
  • 是否含个人/客户/公司敏感信息
  • 能否用更少字段或样例完成
  • 是否符合 AI 使用政策
GATE 02 · 执行前
最坏结果是否可承受？
  • AI 将访问哪些系统/账号
  • 能否预览、撤销、回滚、追踪
  • 是否有付款/删除/发布等高风险
GATE 03 · 发布前
我能为这个结果负责吗？
  • 事实、数字、引用是否已核验
  • 是否侵权、歧视或误导
  • 是否需要标注 AI 与人工审核
